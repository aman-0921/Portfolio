# Aman Chaudhary — Portfolio

This repository contains the source code for my personal portfolio website, designed and developed to showcase my journey as an AI & Full-Stack Developer. The portfolio reflects my approach to building modern software through a clean interface, smooth user experience, and interactive visual elements inspired by an AI Research Lab.

Built with modern web technologies, the website combines responsive design, immersive animations, and a custom 3D background to create an engaging experience while highlighting my projects, technical skills, experience, achievements, and certifications. Every section has been designed to present information in a simple, structured, and professional manner.

The portfolio features some of my notable work, including **Legal Talk**, an AI-powered legal assistance platform, **WanderLust**, a full-stack accommodation booking platform, and **Nexus IoT**, an IoT monitoring platform focused on scalable device management and real-time dashboards. Alongside these projects, the website also showcases my academic background, mentoring experience, hackathon achievements, and technical expertise.

This project was built using HTML, CSS, and JavaScript with a focus on performance, accessibility, and responsive design. It is continuously updated as I learn new technologies, build new projects, and gain more experience.

Feel free to explore the code, provide feedback, or connect with me if you'd like to collaborate on exciting projects.
